# Linear Algebra — PDFs go here

Drop your PDF files directly in this folder (`linear-algebra/pdfs/`), keeping the
file names simple (letters, numbers, hyphens — no spaces if you can
avoid them, e.g. `03-related-rates.pdf` rather than `Related Rates.pdf`).

Then open `../index.html` and add one list item so students see a link
to it. See the **"Adding a new PDF"** section in the root `README.md`
for the exact HTML snippet to copy.
